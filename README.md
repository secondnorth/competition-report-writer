# Competition Report Writer

A Codex skill for developing an evidence-backed competition report through user-approved stages.

Contents:
- skill: reusable skill and its workflow reference.
- source-materials/handbooks: supplied 2025 and 2026 competition handbooks.
- source-materials/rubric: supplied scoring standard.
- source-materials/cases/2024 and source-materials/cases/2025: supplied excellent case report PDFs. Filenames are normalized to avoid carrying contact details from archive filenames.

Only the skill and the supplied competition source materials are included. Personal drafts, outlines, meeting notes, generated reports, and other personal work products are excluded.

The competition documents are included as source material for reference. Their original authors retain their rights; this repository does not assert a license for those documents.
